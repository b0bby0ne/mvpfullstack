# Workflow: EA Requirement

1. Sao chép và điền `../../../templates/EA_Development_Brief.md`.
2. Phân loại bot: control, signal execution hoặc hybrid.
3. Vẽ state transition table và decision table.
4. Chuẩn hóa signal contract, dedup key và expiry.
5. Liệt kê broker/runtime assumptions.
6. Viết happy path, rejection path và recovery path.
7. Review cùng Agent 2, 3 và 4; đánh version brief.
8. Chỉ handoff khi không còn trường bắt buộc mơ hồ.
