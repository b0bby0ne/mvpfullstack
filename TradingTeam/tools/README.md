# TradingTeam Tools

Các runner và công cụ thu thập/quét thị trường dùng đường dẫn chuẩn mới:

- dữ liệu Price Agent: `TradingTeam/agents/Agent_1_PriceAgent/`
- handoff và scanner: `TradingTeam/agents/Agent_2_SwingAgent/`
- trading/research output: `TradingTeam/output/runs/`

Chạy công cụ từ workspace root `D:\Agent` để các đường dẫn tương đối hoạt động đúng.
