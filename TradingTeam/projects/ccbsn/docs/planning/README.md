# CCBSN Sprint Planning

Thư mục này lưu product backlog, sprint plan, review và retrospective của dự
án CCBSN. Quy trình do `Agent_0_Sprint_Manager` điều phối.

Quy ước:

- dùng template `TradingTeam/templates/Sprint_Plan.md`;
- mỗi sprint có một file `SPRINT_<ID>.md`;
- backlog dài hạn dùng `PRODUCT_BACKLOG.md`;
- không lưu Telegram token, account credential hoặc dữ liệu real nhạy cảm;
- release, deployment và Git publish phải ghi trạng thái riêng;
- sprint document không thay thế test evidence hoặc release note.
