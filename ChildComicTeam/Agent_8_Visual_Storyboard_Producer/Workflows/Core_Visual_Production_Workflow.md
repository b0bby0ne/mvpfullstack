# Workflow Visual Development và Storyboard

## Input bắt buộc

- Audience Brief;
- Story Bible và canon version;
- Comic Script;
- Illustration Handoff;
- Research Packet/Source Note khi có;
- visual guide của series;
- rights constraints.

## Quy trình

1. Kiểm tra input và xác nhận script đã qua editorial/safety review.
2. Lập asset inventory: character, expression, location, prop, effect và lettering.
3. Gắn Asset ID và nguồn tham chiếu hợp pháp.
4. Dựng thumbnail toàn tập theo page turn và visual payoff.
5. Review thumbnail với Agent 2, Agent 3 và Agent 5.
6. Tạo model sheet/palette hoặc ghi chính xác asset canon được tái sử dụng.
7. Sản xuất 2–4 trang mẫu để khóa visual quality bar.
8. Chỉ mở batch toàn tập sau khi sample pages được duyệt.
9. Sản xuất hoặc điều phối sketch → line → color → lettering.
10. Kiểm continuity, accessibility, text, rights và export.
11. Tạo `09_Visual_Production_Pack.md` theo [template](../Rules/Visual_Production_Pack_Template.md).
12. Handoff comic package và motion-frame list cho Agent 9.
13. Agent 5 và Creative Lead duyệt Art Gate trước khi phát hành.

Nếu script đổi sau bước 5, dừng batch bị ảnh hưởng, ghi change request và cập nhật version trước khi tiếp tục.
