# Workflow viết Comic Script

1. Đọc Audience Brief, Story Bible và Story Outline.
2. Kiểm tra canon version và target page count.
3. Phân bổ Beat ID/Scene ID theo trang.
4. Chốt page turns và visual payoffs.
5. Viết panel descriptions.
6. Thêm dialogue, caption và SFX.
7. Kiểm tra balloon order, text density và [accessibility/lettering](../Rules/Accessibility_and_Lettering_Rule.md).
8. Kiểm tra visual continuity.
9. Tạo `03_Comic_Script.md`.
10. Trích character, location, prop và page notes.
11. Tạo `05_Illustration_Handoff.md`.
12. Gửi Agent 5 và chia sẻ scene mapping cho Agent 4.
