# Workflow Final QA

1. Kiểm tra đủ tám file output.
2. Xác nhận Story ID và canon version.
3. Chạy safety pass trước.
4. Chạy canon/continuity pass.
5. Chạy age-fit/readability pass.
6. Chạy comic–prose alignment pass.
7. Chạy illustration readiness pass.
8. Kiểm tra source/fact và IP.
9. Ghi issue theo severity và owner.
10. Trả blocker/major cho agent phụ trách.
11. Re-check sau revision.
12. Tạo `06_QA_Report.md` và trạng thái phát hành.
