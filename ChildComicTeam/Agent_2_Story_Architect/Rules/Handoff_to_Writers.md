# Handoff từ Agent 2 tới Agent 3 và Agent 4

Handoff phải có:

- Audience Brief;
- Story Bible;
- canon version;
- Beat ID;
- Scene ID;
- character/world records;
- setup/payoff ledger;
- safety constraints;
- target pages và words;
- comic-specific notes;
- prose-specific notes;
- open questions được phép giải quyết cục bộ.

Agent 3 và Agent 4 không được thay đổi final choice, ending hoặc quan hệ chính độc lập với nhau.
