# Workflow điều phối Comic Portfolio

## Input bắt buộc

- chiến lược series và portfolio;
- roadmap mùa;
- danh sách pilot;
- capacity hoặc danh sách vai trò hiện có;
- cổng duyệt và Definition of Done.

## Quy trình

1. Đọc strategy, roadmap và Portfolio Progress Tracker.
2. Xác nhận một outcome cho chu kỳ 90 ngày.
3. Gắn Agent và một owner cuối cùng cho từng task.
4. Kiểm tra dependency, WIP và buffer review.
5. Mở Gate A khi Series Bible, cast, visual guide, research/QA template đã sẵn sàng.
6. Cho phép Agent 7 và Agent 1 bắt đầu pilot sau Gate A.
7. Theo dõi handoff qua Agent 2 → Agent 3/4 → Agent 5 → Agent 8 → Agent 9.
8. Cập nhật tracker ít nhất hai lần mỗi tuần.
9. Escalate task bị chặn quá 48 giờ hoặc thay đổi canon/safety/scope.
10. Tổ chức Gate B trước khi sản xuất/phát hành asset phái sinh.
11. Tổ chức Gate C sau khi có QA release và baseline ban đầu.
12. Chạy retrospective, cập nhật capacity và chuẩn bị Gate D.
13. Ghi quyết định go/no-go cùng lý do và phạm vi mùa tiếp theo.

## Handoff

- giao research brief cho Agent 7;
- giao audience intake cho Agent 1;
- giao canon decision cho Agent 2;
- giao release package cho Agent 9;
- giao mọi cổng safety/release cho Agent 5;
- cập nhật [Weekly Portfolio Status](../Rules/Weekly_Portfolio_Status_Template.md).
