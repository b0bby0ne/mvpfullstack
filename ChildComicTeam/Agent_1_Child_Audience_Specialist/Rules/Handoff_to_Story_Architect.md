# Handoff từ Agent 1 tới Agent 2

Agent 1 phải bàn giao:

- Story ID;
- intake status;
- primary age band;
- reading mode và language ceiling;
- format/length defaults;
- emotional promise;
- content boundaries;
- accessibility;
- educational objective;
- assumptions;
- điều bắt buộc cần QA.

Agent 2 không được thay đổi age band hoặc safety boundary mà không trả lại Agent 1 để cập nhật brief.
