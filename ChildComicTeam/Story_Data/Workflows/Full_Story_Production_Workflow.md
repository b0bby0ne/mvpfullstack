# Workflow sản xuất truyện đầy đủ

## A. Khởi tạo và research

1. Agent 6 tạo Story ID, task, owner, dependency và hoàn thành Story Intake.
2. Agent 1 đánh giá intake, nhóm tuổi và tạo `00_Audience_and_Intake_Brief.md`.
3. Agent 7 xác định claim/risk, nghiên cứu và tạo `07_Research_Packet.md`.
4. Agent 5 review sớm nếu có nội dung nhạy cảm hoặc rủi ro cao.

Agent 1 và Agent 7 có thể làm song song sau khi intake đủ.

## B. Canon và kịch bản

5. Agent 2 tạo `01_Story_Bible.md`.
6. Agent 2 tạo beat/scene map trong `02_Story_Outline.md`.
7. Agent 5 và Agent 7 xác nhận Outline Gate; khóa canon version.
8. Agent 3 tạo `03_Comic_Script.md` và `05_Illustration_Handoff.md`.
9. Agent 4 tạo `04_Prose_Story.md` từ cùng outline và canon.
10. Agent 5 kiểm tra safety, age-fit, continuity và comic–prose alignment.
11. Sửa lỗi chặn và cập nhật `06_QA_Report.md`.

Comic script và prose story có thể được viết song song sau khi Story Bible và Story Outline đã khóa.

## C. Visual production

12. Agent 8 lập asset register, thumbnail và `09_Visual_Production_Pack.md`.
13. Agent 2, Agent 3 và Agent 5 duyệt thumbnail.
14. Agent 8 sản xuất 2–4 sample pages; chỉ mở batch toàn tập sau khi sample được duyệt.
15. Agent 8 điều phối sketch, line, color, lettering và preflight.
16. Agent 5 và Agent 2 duyệt Art Gate; Agent 7 kiểm claim/chi tiết văn hóa xuất hiện trong art.

## D. Chuyển thể và phát hành

17. Agent 7 tạo `08_Source_Note.md` từ claim thực sự xuất hiện trong sản phẩm.
18. Agent 9 tạo `10_Adaptation_and_Distribution_Plan.md` và các prototype motion/short-form.
19. Agent 5 kiểm tra release safety; Agent 6 kiểm dependency; Agent 8 kiểm visual continuity/rights.
20. Agent 9 phát hành canon/owned library trước, clip khám phá sau.
21. Agent 9 tạo `11_Release_and_Metrics_Report.md`, moderation/correction log và baseline.
22. Agent 6 chạy retrospective, cập nhật portfolio tracker và quyết định bước tiếp theo.
23. Cập nhật `Master_Index.md` và version log.

Không bắt buộc mọi truyện backlog phải tạo motion asset. Khi một tập được chọn làm pilot hoặc release package, các bước C/D và các output `09–11` là bắt buộc.
