# Workflow sản xuất truyện đầy đủ

1. Tạo Story ID và hoàn thành Story Intake.
2. Agent 1 đánh giá intake, nhóm tuổi và tạo `00_Audience_and_Intake_Brief.md`.
3. Agent 2 tạo `01_Story_Bible.md`.
4. Agent 2 tạo beat/scene map trong `02_Story_Outline.md`.
5. Khóa canon version trước khi viết chi tiết.
6. Agent 3 tạo `03_Comic_Script.md`.
7. Agent 4 tạo `04_Prose_Story.md` từ cùng outline và canon.
8. Agent 3 tạo `05_Illustration_Handoff.md`.
9. Agent 5 kiểm tra safety, age-fit, continuity và comic–prose alignment.
10. Sửa lỗi chặn phát hành.
11. Agent 5 tạo `06_QA_Report.md`.
12. Cập nhật `Master_Index.md`.

Comic script và prose story có thể được viết song song sau khi Story Bible và Story Outline đã khóa.
