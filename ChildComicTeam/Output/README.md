# Output

Mỗi story project dùng:

```text
Output/<story_id>/
├── Master_Index.md
├── 00_Audience_and_Intake_Brief.md
├── 01_Story_Bible.md
├── 02_Story_Outline.md
├── 03_Comic_Script.md
├── 04_Prose_Story.md
├── 05_Illustration_Handoff.md
├── 06_QA_Report.md
├── 07_Research_Packet.md
├── 08_Source_Note.md
├── 09_Visual_Production_Pack.md
├── 10_Adaptation_and_Distribution_Plan.md
└── 11_Release_and_Metrics_Report.md
```

## Trạng thái

- `Intake`
- `Research`
- `Architecture`
- `Writing`
- `QA`
- `Ready for illustration`
- `Visual production`
- `Release QA`
- `Scheduled`
- `Live/Measuring`
- `Revision`
- `Archived`

Các output `00–06` là lõi của một story project. `07` là bắt buộc khi có claim khoa học, sức khỏe, an toàn, văn hóa hoặc địa phương. Với pilot/release package của portfolio, các output `07–11` đều bắt buộc.

## Project template

Sao chép cấu trúc trong [`_Project_Template`](./_Project_Template/Master_Index.md) cho dự án mới, sau đó thay toàn bộ placeholder `<...>`.
