# LiveJP Creator prototype

Open `index.html` in a modern browser. It requires no build step or network connection.

## Main walkthrough

1. Select email or phone sign-in and press `ログイン`.
2. On Creator Dashboard, press `ライブを始める`.
3. Review camera/mic/connection readiness and press `ライブを開始`.
4. In Studio, observe viewer count and incoming comments from the separate audience app.
5. Press `終了`, confirm, and review the viewer summary.

History, Analytics, and Account are available from bottom navigation.

## Scope

- UI prototype only; all data is local sample data.
- No viewer playback experience is included.
- Camera, microphone, authentication, chat, analytics, and streaming are not implemented.
