# LiveJP — Master Project Index

## Project status

- Phase: UI/UX design only
- Target platforms: iOS and Android
- Market: Japan
- Backend/API: Out of scope
- Monetization: None
- Content policy: General-audience livestreaming; adult content is excluded

## Confirmed product decisions

1. The mobile app uses the same user account as the existing website.
2. Users sign in with email or phone number.
3. LiveJP is a creator-only broadcasting app; viewers watch from a separate audience app.
4. Any creator account may start a livestream.
5. The product is entirely free.
6. Primary KPIs are live viewers (generated in the audience app) and the active-creator ratio compared with the main app.
