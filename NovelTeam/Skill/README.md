# Skill (Kỹ năng sáng tác)

Nơi thiết lập và lưu trữ các kỹ năng cần thiết để triển khai bộ truyện.

## Danh mục kỹ năng
- **Kỹ năng viết truyện**: Cách dẫn dắt, nhịp độ (pacing), mô tả cảnh vật và cảm xúc.
- **Kỹ năng xây dựng nhân vật**: Tâm lý học nhân vật, mâu thuẫn nội tâm, phát triển nhân vật (character arc).
- **Kỹ năng triển khai Story**: Cách chuyển đổi từ ý tưởng sang các chương truyện, kỹ thuật cliffhanger, foreshadowing.
