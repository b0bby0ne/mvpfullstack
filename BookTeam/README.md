# BookTeam

BookTeam là hệ thống quản lý affiliate marketing sách theo hai lớp:
* Nguyên tắc chung ở root level.
* Topic portfolios cho từng ngách nội dung.

Thư mục `Ref/` đã được tích hợp vào các tài liệu chính:
* `Global_Guideline.md`
* `Master_Index.md`
* `Skills/Article_Writing.md`
* `Workflows/Content_Production.md`

## Cấu trúc
* `Knowledge/` - framework, landscape, portfolio strategy.
* `Workflows/` - setup, production, update.
* `Skills/` - analytics, writing, strategy, enrichment.
* `Rules/` - compliance, standards, quality.
* `Topic_*/` - portfolio và distribution theo từng chủ đề.
* `Ref/` - kho pattern đã hợp nhất vào hệ thống, còn lại để tham chiếu và mở rộng.
