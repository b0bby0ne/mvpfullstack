# Nghiên Cứu Phong Cách Viết - Framework Thực Thi

Tài liệu này mô tả quy trình thu thập, phân tích và tích hợp phong cách viết vào hệ skill.

## Quy trình
1. Đọc file framework.
2. Đọc file kết quả hiện tại.
3. Chọn 3 đến 5 bài tiếp theo.
4. Phân tích và ghi kết quả.
5. Sau mỗi batch, cập nhật bảng tổng hợp pattern.

## Mục tiêu
* Tách pattern mới.
* Gắn pattern vào đúng module.
* Giữ instruction gọn, không tràn ngữ cảnh.
