# Kiểm Toán Phong Cách Viết

Tài liệu này phân tích từng bài mẫu để rút ra DNA phong cách và điểm cần bổ sung vào skill.

## Cách làm
* Đọc từng bài.
* Xác định hook, chuyển ý, nhịp đoạn và kết bài.
* Ghi lại pattern mới theo format chuẩn.

## Kết quả mong muốn
* Có bảng tổng hợp pattern.
* Có đề xuất file skill đích.
* Có ghi chú cập nhật ngữ cảnh sau mỗi batch.
