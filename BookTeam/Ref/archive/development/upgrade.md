# Nâng Cấp Hệ Thống

Tài liệu này ghi lại các pattern mới, đề xuất bổ sung và thay đổi cấu trúc hệ thống.

## Quy tắc
* Phát hiện pattern mới thì ghi lại ngay.
* Đề xuất file đích rõ ràng.
* Cập nhật lead file trước rồi mới sửa chi tiết.

## Mục tiêu
* Hệ thống dễ duy trì.
* Instruction không quá dài.
* Mỗi pattern có chỗ đứng rõ ràng.
