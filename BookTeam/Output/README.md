# Thư mục Output

Thư mục này dùng để lưu trữ kết quả phân tích thực tế từ các phiên chạy của BookTeam.

## Quy ước đặt tên
* `[YYYY-MM-DD]_Run_Intake.md`
* `[YYYY-MM-DD]_Book_Portfolio.md`
* `[YYYY-MM-DD]_Content_Plan.md`
* `[YYYY-MM-DD]_Performance_Report.md`

## Nguyên tắc
* Mỗi file báo cáo phải nằm trong thư mục này hoặc thư mục con của nó.
* Không lưu file nháp lộn xộn ở thư mục gốc của dự án.
