# Output

Mỗi advisory run dùng một thư mục:

```text
Output/<advisory_id>/
├── Master_Index.md
├── 01_Astro_Event_Brief.md
├── 02_Market_Context.md
├── 03_Cross_Asset_Impact.md
└── 04_Advisory_Report.md
```

## `Master_Index.md`

Phải ghi:

- Advisory ID;
- Event ID;
- snapshot time;
- asset coverage;
- trạng thái;
- confidence;
- time sensitivity;
- thứ tự đọc.

Output không chứa kế hoạch, chiến lược hoặc chỉ dẫn thực thi giao dịch.
