# Advisory Data Workspace

```text
Data/
├── events/
├── contexts/
├── sources/
└── advisories/
```

- `events/`: Astro Event Brief hoặc event record đã xác minh.
- `contexts/`: market snapshot theo timestamp.
- `sources/`: source records và tài liệu tham chiếu.
- `advisories/`: archive các báo cáo đã phát hành.

Chỉ lưu dữ liệu cần cho tư vấn. Không lưu API key, thông tin tài khoản, vị thế hoặc dữ liệu giao dịch cá nhân.
