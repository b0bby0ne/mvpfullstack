# Quy trình xử lý sự kiện chiêm tinh

1. Nhận câu hỏi và phạm vi thời gian.
2. Xác định event cần kiểm tra.
3. Lấy ephemeris từ nguồn đã phê duyệt.
4. Chuẩn hóa exact time và timezone.
5. Ghi cấu hình tính toán.
6. Xác định active window.
7. Tóm tắt ý nghĩa chiêm tinh truyền thống.
8. Ghi các chủ đề thị trường có thể liên quan ở mức giả thuyết.
9. Tạo `01_Astro_Event_Brief.md`.
10. Handoff cho Agent 2 và Agent 3.
