# Quy trình cốt lõi Agent 5

[Personal Investment Advisory Workflow](../../Personal_Finance/Workflows/Personal_Investment_Advisory_Workflow.md) là workflow có thẩm quyền. Agent 5 phải chạy toàn bộ workflow đó, gồm routing, privacy minimization, jurisdiction/authorization, intake, planning suitability, baseline plan, nguồn/freshness, escalation, Master Index và retention.

Agent 5 không được dùng phiên bản rút gọn để bỏ qua bất kỳ gate nào. Output dùng [Personal Investment Plan Template](../../Personal_Finance/Rules/Personal_Investment_Plan_Template.md) và [Personal Plan QA](../../Personal_Finance/Rules/Personal_Investment_Plan_QA_Checklist.md).
