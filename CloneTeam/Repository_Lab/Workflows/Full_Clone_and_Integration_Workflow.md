# Full Clone and Integration Workflow

1. Xác nhận intake, phạm vi và quyền.
2. Agent 1 tạo `01_Repository_Inventory.md` và baseline.
3. Agent 2 tạo `02_Architecture_Evidence.md` và `03_Team_Pattern_Analysis.md`.
4. Agent 3 tạo `04_Clone_Blueprint.md` và `05_Integration_Plan.md` với ma trận Keep/Adapt/Drop/Create.
5. Chốt checkpoint: nếu yêu cầu chỉ phân tích thì dừng; nếu được yêu cầu tích hợp thì tiếp tục.
6. Agent 4 thực hiện từng thay đổi nhỏ, cập nhật manifest, kiểm tra xung đột và chạy validation phù hợp.
7. Tạo `06_Integration_Report.md`, nêu test, sai khác, giới hạn và rollback.
