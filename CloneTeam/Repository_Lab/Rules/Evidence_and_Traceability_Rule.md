# Evidence and Traceability Rule

Mỗi phát hiện dùng định dạng: `repo`, `ref/commit nếu có`, `path`, `dòng hoặc ký hiệu`, `loại bằng chứng`, `diễn giải`, `confidence`.

Ưu tiên: chỉ dẫn vận hành và tài liệu kiến trúc → manifest/config/test → code → lịch sử git → suy luận từ tên. Không dùng output sinh ra hoặc file vendor làm bằng chứng thiết kế chính nếu chưa xác minh.
