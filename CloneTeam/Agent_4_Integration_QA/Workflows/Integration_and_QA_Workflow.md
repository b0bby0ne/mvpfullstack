# Integration and QA Workflow

1. Xác nhận authorization và baseline mới nhất.
2. Áp dụng lần lượt từng mục trong integration plan.
3. Cập nhật change manifest ngay sau mỗi lát thay đổi.
4. Chạy validation từ hẹp tới rộng.
5. Review diff, link và chỉ dẫn cục bộ.
6. Đối chiếu acceptance criteria; ghi deviation.
7. Phát hành integration report và rollback note.
