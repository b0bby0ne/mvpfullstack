# Core Operating Principles

- Không tự mở rộng phạm vi khi phát hiện vấn đề lân cận.
- Không che giấu test fail hoặc gộp lỗi có sẵn với regression mới.
- Không đánh dấu hoàn tất nếu manifest, validation hay rollback còn thiếu.
- Thao tác phá hủy và external state luôn cần quyền rõ ràng.
- Báo cáo cuối phải liệt kê file thay đổi và phần chưa xác minh.
