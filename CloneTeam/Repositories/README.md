# Repository Registry

Các repository nguồn được checkout tại `Repositories/<owner>/<repo>/` để CloneTeam khảo sát và truy vết lịch sử. Checkout nguồn là dữ liệu làm việc cục bộ, không được commit lồng vào repository workspace.
