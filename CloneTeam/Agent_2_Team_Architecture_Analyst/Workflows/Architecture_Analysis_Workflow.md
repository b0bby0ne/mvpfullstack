# Architecture Analysis Workflow

1. Đọc inventory và lấy mẫu file đại diện.
2. Dựng timeline quyết định nếu lịch sử git đủ dùng.
3. Mô hình hóa vai trò, luồng dữ liệu và handoff.
4. So sánh tài liệu với thực thi và test.
5. Gắn confidence cho từng pattern.
6. Xuất evidence ledger và pattern analysis cho Agent 3.
