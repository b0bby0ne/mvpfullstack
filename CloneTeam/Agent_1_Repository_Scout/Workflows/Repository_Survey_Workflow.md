# Repository Survey Workflow

1. Chuẩn hóa danh sách repo và ref.
2. Đọc chỉ dẫn áp dụng theo từng đường dẫn.
3. Ghi baseline git và inventory công nghệ.
4. Lập bản đồ các thành phần tạo team và quan hệ giữa chúng.
5. Ghi bằng chứng vào `01_Repository_Inventory.md`.
6. Handoff các khoảng trống và cảnh báo cho Agent 2.
